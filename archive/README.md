# Archive — superseded planning and reference documents

Moved here 2026-09-11. Nothing is deleted; these remain useful as history and as the
record of *why* branches were parked. Live documents stay at the repo root.

**Why archived:** the nuPlan leaderboard was wiped and re-run on a private 1000-rollout
scene set (SETUP-NOTES §6.48/§6.50), which invalidated most pre-reset board analysis, and
two engineering branches (route selection, route follower) were measured and parked.
